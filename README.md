# 🕵️ Cold Case

A noir detective game built across a 10-week vibe coding challenge.

**Week 2 status:** Multi-file structure + 100 playable cases.

## Play

https://ashlynnbhatia02-plixel.github.io/Game1/

## Structure

- `index.html` — page structure
- `styles.css` — all styling
- `js/main.js` — entry point
- `js/controller.js` — user input handling
- `js/renderer.js` — DOM rendering
- `js/state.js` — game state
- `js/case.js` — case loading logic
- `data/cases.js` — 100 cases (10 hand-crafted, 90 generated)
